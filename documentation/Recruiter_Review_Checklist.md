# Recruiter Review Checklist

Before putting this repository on your CV:

- [ ] Execute manual test cases and replace `Not Run` statuses with real results.
- [ ] Keep only defects you actually reproduced and attach evidence.
- [ ] Export a real Newman report after running the Postman collection.
- [ ] Run Playwright locally and keep the HTML report out of Git unless you intentionally publish it.
- [ ] Push to GitHub and confirm GitHub Actions completes.
- [ ] Update `Test_Summary_Template.md` with real metrics.
- [ ] Add 2–4 screenshots to the README (test case sheet, API run, automation report, CI run).
- [ ] Put the GitHub URL on the CV under Projects.
- [ ] Be ready to explain one defect, one API validation, one SQL query, and one automation design choice in an interview.
