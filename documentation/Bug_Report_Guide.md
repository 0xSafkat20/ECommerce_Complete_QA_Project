# Bug Reporting Guide

Use a short, specific title and include environment, precondition, exact steps, expected result, actual result, severity, priority, status, and evidence.

## Severity Guide
- **Critical:** Core journey impossible, major data/security impact, or application unusable.
- **Major:** Important feature fails with no reasonable workaround.
- **Minor:** Limited functional/usability impact with workaround.
- **Trivial:** Cosmetic/text-only issue.

## Evidence
Store screenshots in `evidence/bug-evidence/` and reference the filename from the defect log.

## Ethics
The included `BUG-TPL-*` records are hypothetical formatting examples, not verified live defects.
